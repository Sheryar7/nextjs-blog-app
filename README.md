# Next.js Blog App

A modern blog application built with Next.js (App Router) and Tailwind CSS.

## 🚀 Features

- File-based routing
- Dynamic routes (/posts/[id])
- Data fetching using async/await
- Loading and error handling
- Responsive modern UI

## 🧠 What I Learned

- Next.js App Router
- Server vs Client components
- API integration
- Component-based architecture

## 🔧 Tech Stack

- Next.js
- React
- Tailwind CSS
